Definieert eigen Elementor-widgets voor Unique Waterontharders.

== Description ==

Deze plugin voegt een eigen widgetcategorie "Unique Waterontharders" toe aan de
Elementor-editor. Elementor moet geïnstalleerd en geactiveerd zijn: activeren zonder
Elementor wordt geweigerd, en als Elementor later wordt uitgeschakeld toont de plugin
een melding in het adminpaneel in plaats van widgets te registreren.

Meegeleverde widgets:

* **Waarom** — titel plus een herhaalbare lijst met items (afbeelding, titel en
  tekst per item). Weergave volgt nog.

== Installation ==

1. Upload de plugin naar `/wp-content/plugins/unique-waterontharders`.
2. Zorg dat Elementor geïnstalleerd en geactiveerd is.
3. Activeer de plugin via het 'Plugins'-menu in WordPress.
